지금 실제로 연결된 데이터

  • 음식점·카페·간편식: OpenStreetMap Overpass API (사용자 조회 시)
  • 지역명 선택: Nominatim (검색·현 위치 조회 시)
  • 지도 타일: OpenStreetMap 기여자
  • 즐겨찾기·개인 별점·메모: 내 기기 LocalStorage (수집 서버 없음)

운영 데이터 상태

  • 전국 음식점 인허가·휴폐업: 미연동
  • 식약처 위생등급: 미연동
  • 메뉴 가격/리뷰/예약: 미연동
  • 일별 전국 데이터 수집/커버리지 추적: 미구현

운영 단계에는 전국 데이터 공급처별 전체·수집·변경·오류 건수를 분리하고 데이터 기준일 및 라이선스를 표시합니다.
