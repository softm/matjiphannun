행정상 영업·폐업 대조용 전체 인허가 자료는 아직 연결하지 않았습니다. C004 폐업·취소 정보는 해당 지정업소의 배지 유효성 검사에만 사용합니다.

지도·갱신 방식

  • 지도·주소 검색: 네이버 Maps JavaScript SDK
  • 식당 목록: 지역별 공개 JSON. 사용자 위치에서 필요한 지역만 읽습니다.
  • 수집기: 공공 API 키를 사용하는 별도 배치. 키는 화면·APK에 포함하지 않습니다.
  • 방문 메모·즐겨찾기·개인 평가: 기기 내부 저장, JSON 백업·복원

위생정보 미표시는 위생이 나쁘다는 뜻이 아닙니다. 메뉴 가격·방문자 리뷰·실시간 영업 여부를 추정해 표시하지 않습니다.

공식 출처와 이용조건

  • 소상공인시장진흥공단 상가(상권)정보 — 기본 상호·업종·주소·좌표
  • 한국관광공사 TourAPI — 관광 음식점·사진. 공공누리 3유형은 원본 비율로 표시하며 자르기·가공하지 않습니다.
  • 식품의약품안전처 C004 — 식품안심업소(위생등급) 지정정보
